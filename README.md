# PadVision

A live TV and M3U playlist player for Android tablets, built with Kotlin, Jetpack Compose and Media3.

## Features

- **Live TV** — Browse and play channels from any M3U/M3U8 playlist URL
- **EPG support** — Electronic Program Guide with grid and list view
- **Playlist library** — Save and manage multiple M3U playlists
- **Extra sources** — One-tap add for curated free public sources:
  - Free-TV Global, Indian TV
  - Pluto TV, Samsung TV Plus, Plex TV, Stirr TV
  - Korean Channels, Music Channels (Global)
- **Channel filtering** — Filter by category, search by name
- **Favourites** — Pin channels for quick access
- **Kids mode** — Filter to family-friendly content only
- **Quality filter** — Set minimum stream quality (SD/HD/FHD/4K)
- **Channel rename & hide** — Customise your channel list
- **Watch time tracker** — See how long you've watched

## Requirements

- Android tablet (≥ 600dp screen width recommended)
- Also works on phones
